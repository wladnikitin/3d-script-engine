Inside this folder, there is a file that must always be named "camera.txt".
The camera values in this file are written in the following format:

x-coordinate: [float]; y-coordinate: [float]; z-coordinate: [float]; horizontal angle: [float] degrees; vertical angle: [float] degrees

They represent the following:

x, y, z — the position of the camera in 3D space (in centimeters)

horizontal angle — rotation left/right (in degrees)

vertical angle — rotation up/down (in degrees)
